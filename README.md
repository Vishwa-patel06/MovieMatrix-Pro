# 🎬 MovieMatrix Pro — Intelligent Movie Recommendation System

An interactive, machine learning-based movie analytics and recommendation project built with Python and Streamlit. MovieMatrix Pro explores movie data, visualizes trends, and predicts movie preferences using machine learning.

## 🚀 Live Demo

**Try the application:** https://moviematrix-pro-vishwa.streamlit.app/

## 📌 Project Overview

MovieMatrix Pro is designed to explore movie preferences and provide insights into movie ratings, genres, and user behavior through an interactive web application.

The application includes a dashboard, dataset explorer, prediction section, and project description.

## ✨ Features

- **Dashboard:** View key movie statistics and summary metrics.
- **Dataset Explorer:** Explore the movie dataset and its attributes.
- **Data Visualization:** Analyze movie genres and user rating distributions.
- **Machine Learning Prediction:** Use a Random Forest classifier to predict movie preference outcomes.
- **Interactive Interface:** Navigate between sections using Streamlit.

## 🛠️ Tech Stack

- **Programming Language:** Python
- **Web Framework:** Streamlit
- **Data Analysis:** Pandas
- **Data Visualization:** Matplotlib
- **Machine Learning:** Scikit-learn
- **Model:** Random Forest Classifier
- **Data Preprocessing:** Label Encoding

## ⚙️ Installation and Setup

### 1. Clone the repository

```bash
git clone https://github.com/Vishwa-patel06/MovieMatrix-Pro.git
cd MovieMatrix-Pro
```

### 2. Create a virtual environment (recommended)

```bash
python3 -m venv .venv
source .venv/bin/activate
```

### 3. Install dependencies

```bash
pip install -r requirements.txt
```

### 4. Run the application

```bash
streamlit run 1.py
```

The application will open in your browser, usually at `http://localhost:8501`.
